# Migration Pulse Hub — Website

Source for the public website of Migration Pulse Hub ([migrationpulsehub.org](https://migrationpulsehub.org)): a static HTML/CSS/JavaScript site hosted on Netlify, with a Netlify Function (`netlify/functions/fetch-news.js`) that proxies RSS news feeds and a contact form submitted through Netlify Forms/EmailJS.

**Deployment:** Netlify publishes the repository root (`netlify.toml`). Every push to the default branch redeploys the live site, so test changes locally first (`npx serve .`).
