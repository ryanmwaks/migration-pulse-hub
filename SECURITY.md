# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in this project,
please report it privately. **Do not open a public GitHub issue.**

- Email: **info@zuriitconsults.com** (subject line: `SECURITY — <repository name>`)
- Include: a description of the issue, steps to reproduce, the affected URL or
  file, and any proof-of-concept (no real user data, please).

We aim to acknowledge reports within 3 working days and to agree a fix and
disclosure timeline with you.

## Scope

This policy covers the code in this repository and the site it deploys.
Third-party services and libraries should be reported to their maintainers.

## Safe harbour

We will not take action against good-faith research that avoids privacy
violations, data destruction and service disruption, and that gives us
reasonable time to fix the issue before disclosure.
